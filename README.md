# InTreatment — прототип подбора психолога

Путь клиента: **чат → карточка психолога и календарь → регистрация → личный кабинет**.
Оплата происходит уже внутри платформы: в кабинете висит неоплаченный заказ, оттуда
**кабинет → оплата → готово → кабинет**. Тем же путём покупаются продукты самопомощи —
их заказ проходит через регистрацию и кабинет (см. `lib/order.js`).

Собрано с оглядкой на PRD «Продуктовые требования платформа Intreatment»: вход только через
Яндекс ID / VK ID (7.1), почта из SSO подставляется в оплату (7.1), способы оплаты — карта РФ,
зарубежная карта и СБП (5А.1), чек всегда на email (5А.1), слоты с шагом 30 минут (5А.2),
отпуск психолога с подписью и листом ожидания (7.4), выдача нескольких подходящих
специалистов (6.10, 7.3).

Собран по экранам из Figma (файл Mary, ноды `9224-7988` и `9264-7260`) в стилистике сайта
[intreatment](https://vikahramovich02-collab.github.io/intreatment/): Playfair Display в заголовках,
Helvetica Neue в интерфейсе, чернила `#2d2c2a`, без цветных акцентов — только белый, серый и штрих.

Кнопки и поля взяты из макета подбора: скругление 10px, высота 48, светло-серые `#efefef`,
тёмная `#181616` только у главного действия. Шапка повторяет пропорции сайта — размеры считаются
от ширины экрана (`clamp` c `vw`), поэтому кнопки в ней мельче, чем в теле экрана.
Модалки оформлены как диалог «Оставить заявку» на сайте: прямые углы, воздух, заголовок Playfair капсом.

**Живой прототип:** https://vikahramovich02-collab.github.io/intreatment-podbor/

## Запуск

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть прод-сборку
```

## Деплой

```bash
bash deploy.sh
```

Собирает `dist` и заливает его в ветку `gh-pages` репозитория
`vikahramovich02-collab/intreatment-podbor`. Pages пересобирается 1–2 минуты.
`base` в `vite.config.js` — относительный (`./`), поэтому одна и та же сборка
работает и локально, и в подпапке Pages.

## Как устроен чат

Разговор начинается сразу с вопроса «Как к вам можно обращаться?» — без кнопки старта.
В мультивыборе последним пунктом идёт «Ничего из этого»: он взаимоисключающий, а после него
ассистент просит рассказать своими словами (шаг `own_words`).
Реплики подписаны брендом «InTreatment»; ответ на свободный текст дополнительно подписывается
«Дежурный психолог Дарья».

## Согласие на обработку данных (152-ФЗ)

До первого ответа под полем ввода стоит **пустой** чекбокс согласия: галочка не проставлена
заранее — предзаполненное согласие не считается надлежащим. Пока чекбокс не отмечен, поле
ввода и варианты ответа заблокированы; после отметки чекбокс исчезает и разговор начинается.

В тексте согласия отдельно названы сведения о самочувствии: ответы в чате относятся к
специальной категории персональных данных (данные о здоровье), и обрабатывать их без явного
согласия нельзя. Формулировку и состав согласий (одно общее или отдельное на спецкатегорию)
должен утвердить юрист — в прототипе стоит рабочий вариант.

После карточки доступны только уместные действия: «Показать другого специалиста» и
«Обсудить другую тему». Плашка «Ближайшая запись» кликабельная — открывает расписание.

Расписание показывается сразу на месяц. Часовой пояс определяется автоматически (UTC+3)
и меняется вручную — список с городами РФ от Калининграда до Камчатки; слоты, ближайшая
запись и подпись времени пересчитываются под выбранный пояс. База — московское время,
см. `BASE_UTC` в `lib/format.js`.

Полоса прогресса в шапке содержит только путь до входа на платформу — «Подбор» и
«Регистрация»; оплата происходит уже внутри кабинета. По пройденной точке можно вернуться
в подбор.

Запись — чёрной кнопкой «Записаться» в зоне действий под чатом; в самой карточке остаётся
только ссылка на профиль.

Пути к фото и видео строятся от базового пути сборки (`asset()` в `lib/format.js`) —
иначе в подпапке GitHub Pages файлы отдавали 404.
Варианты ответа раскладываются в две колонки, если их четыре и больше. Мультивыбор
подтверждается кнопкой поля ввода (она меняет подпись на «Продолжить»), рядом тихая ссылка
«Ничего из этого» — отдельной большой кнопки нет.

В шапке слева — «Экстренная помощь» и «Самопомощь»: оба пункта открывают попап быстрой помощи,
второй сразу проматывает к каталогу. На узких экранах пункты прячутся, вход остаётся из строки
под чатом.

## Как работает подбор

Алгоритм перенесён один в один из бота InTreatment (`bogomazdmitry/intreatment`,
`intreatment_bot/data/categories.py`) в `src/data/categories.js`:

- 10 пунктов главного меню — 8 сфер плюс «Скорая помощь» и «Написать дежурному психологу»;
- у каждой сферы свои подкатегории, у шести подкатегорий есть третий уровень;
- выбор доводит до **v-кода**, по нему показывается описание ситуации («Узнаёте себя?»)
  и список специалистов из `V_CODE_SPECIALISTS` — в том же порядке, что в боте.

Шаги чата повторяют бота: имя → категория → подкатегория → третий уровень →
узнавание ситуации → выдача специалистов. Пункты ситуации показываются чекбоксами:
можно отметить свои или описать словами — свободный текст уходит дежурному психологу.
На каждом шаге доступны «Шаг назад» (история состояний) и «Вернуться к темам». Свободный текст в любой момент сопоставляется
с категорией по ключевым словам.

Имена, описания и цены специалистов взяты из `intreatment_bot/data/psychologists.py`.
Фотографии есть у шести из восьми, расписание пока демонстрационное.

Над списком вариантов есть возврат «← Вернуться к категориям» — как быстрый переход
к началу дерева, аналог меню категорий в боте.

## Несколько тем в одном разговоре

У клиента редко один запрос. Ответ на вопрос о сфере открывает **тему** — свою ветку со своими
метками и своим подобранным специалистом. После карточки есть вариант «Обсудить другую тему»:
метки обнуляются, начинается новая ветка.

Слева от ленты — «содержание» разговора (`TopicsPanel`): список тем с подобранным психологом,
клик прокручивает чат к началу этой темы. Панель прячется на экранах уже 1320px.

## Редактирование ответа

Каждая реплика клиента хранит снимок состояния до ответа (`snapshot`: шаг, метки, тема, имя).
Кнопка «Изменить ответ» откатывает чат к этой точке, возвращает текст в поле ввода — дальше
подбор идёт заново от нового ответа.

## Быстрая помощь и допродукты

Строка «Если вам сейчас небезопасно» ведёт в попап «Помощь прямо сейчас». Порядок блоков
принципиальный: сначала бесплатная экстренная помощь, и только ниже платные материалы —
человеку в остром кризисе мы ничего не продаём. Внутри попапа мини-флоу:
список → карточка продукта → оплата → «забрать».

## Мобильная версия

Прототип проверяется на 390×844. Что отличается от десктопа:

- шапка: пункты слева и прогресс воронки прячутся, остаются логотип и «Войти»;
- темы разговора вместо боковой панели идут горизонтальной лентой над чатом;
- «Изменить ответ» уходит под пузырь реплики и видно без наведения;
- варианты ответа всегда в одну колонку;
- оплата: сумма и кнопка «Оплатить» — в липкой панели снизу (в сводке кнопка скрыта),
  способ оплаты раскладывается в столбик;
- кабинет: разделы — горизонтальной лентой вкладок;
- модалки занимают высоту экрана, заголовок не заезжает под крестик.

## Что демо

- Психологи, их расписание и цены — выдуманные данные в `specialists.js`.
- Видео-визитка — один и тот же демо-ролик у двух специалистов (`public/img/psy-video.mp4`).
- Каталог быстрой помощи в `products.js` — названия и цены черновые, под утверждение.
- Код из СМС всегда `1234`, промокод `FIRST` даёт −10%.
- Email для чека обязателен при любом способе оплаты.
- Поле карты подставляет тестовый номер по клику, оплата ничего не списывает.
- Расписание строится от сегодняшнего дня; на сегодня показываются только слоты,
  до которых осталось больше двух часов.

## Что осталось для боевой версии

- Реальные анкеты и расписание психологов из админки.
- Настоящая авторизация (СМС-провайдер, Яндекс ID, VK ID) и платёжный шлюз.
- Резерв слота на бэкенде — сейчас таймер 20 минут только визуальный.
- Тексты кризисной ветки согласовать с Екатериной, добавить телефоны линий помощи по регионам.
- Видео-визитки психологов: снять, обрезать в квадрат, ужать (сейчас демо-ролик на 2 МБ —
  для боевой версии нужен CDN и постеры отдельными картинками).
- Состав и цены допродуктов, а также где ещё показывать этот попап (кабинет, письма, ожидание встречи).
